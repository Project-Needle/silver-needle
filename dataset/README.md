# Dataset Resources

A collection of benchmark datasets with ground-truth answers for evaluating LLM providers.

| Dataset | Type | Difficulty | Description |
|---------|------|------------|-------------|
| [AI2-ARC](https://huggingface.co/datasets/allenai/ai2_arc) | Multiple choice (single) | Easy / Hard | Mixed-domain reasoning questions, split into ARC-Easy and ARC-Challenge subsets. |
| [C-Eval](https://huggingface.co/datasets/ceval/ceval-exam) | Multiple choice (single) | Medium | Chinese-language exam questions covering diverse academic and professional domains. |
| [GSM8K](https://huggingface.co/datasets/openai/gsm8k) | Math (numeric answer) | Medium | Grade-school math word problems with step-by-step reasoning traces and numeric answers. |
| [IFEval](https://huggingface.co/datasets/google/IFEval) | Instruction following | N/A | Instruction-based dataset with no fixed answer; evaluates whether specific verifiable constraints are satisfied. |
| [MMLU-Pro](https://huggingface.co/datasets/TIGER-Lab/MMLU-Pro) | Multiple choice (single, 10 options) | Hard | Domain-specific harder variant of MMLU with 10-option questions across many subjects. |
| [GPQA](https://huggingface.co/datasets/Idavidrein/gpqa) | Short answer | Expert | PhD-level questions in biology, physics, and chemistry; designed to be unsearchable and extremely difficult. |
| [Humanity's Last Exam (HLE)](https://huggingface.co/datasets/cais/hle) | Short answer (some multimodal) | Frontier | Mixed-domain open-ended questions, some with images; currently the hardest public benchmark — top models answer only ~50%. |
